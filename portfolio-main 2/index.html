WORKFLOW TROUBLESHOOTING

No-show Recovery — SMS Consent Failure

RETEST PASSED WITH FALLBACK

Issue: The SMS step failed because Isabella Garcia’s contact record did not contain SMS consent information. The workflow attempted to send without being able to verify SMS eligibility. The task action also had no configured task owner.

Root cause

  • Missing SMS consent / eligibility check before sending.
  • No manual follow-up fallback for contacts without consent.
  • Task owner was not configured.

Repair performed

  • Added an SMS consent/eligibility check.
  • Added manual follow-up task fallback when consent is absent.
  • SMS is sent only when consent is confirmed.
  • Configured Front Desk as task owner.
  1. Audit the failed execution log

    Opened the failed WF-03 run for Isabella Garcia and reviewed the SMS eligibility error.

  2. Inspect the workflow and contact scenario

    Confirmed the no-show test contact had no SMS consent and the workflow lacked consent-handling logic.

  3. Repair the workflow configuration

    Added consent-check and fallback steps and assigned Front Desk as task owner.

  4. Retest the same scenario

    Ran the no-show test for Isabella Garcia with consent set to No.

  5. Verify the result

    Confirmed PASS WITH FALLBACK: SMS skipped due to no consent and manual follow-up configured.

Screenshot sequence: failed execution log → troubleshooting notes → edited workflow → test configuration → pass-with-fallback result. Original screenshot files were not included in the uploaded portfolio ZIP; add them here when available.

  3. Retest

    Ran the test again after activation.

  4. Verify

    Confirmed the pass result and four simulated steps.
